# MyAnimalRoom landing website

This repository contains the public MyAnimalRoom product website. `docs/` is the permanent GitHub Pages publishing directory (`main` branch, `/docs` folder), not a temporary staging folder. It is served at the domain root; visitors do not see `/docs` in the URL.

The site frontend is static HTML, CSS and browser JavaScript, without Jekyll or a site bundler. Product information and room/growth illustrations remain readable without JavaScript. The interactive previews demonstrate the app; they do not create focus sessions or save visitor data. Only the public suggestions board uses a separate storage API, described below.

## Develop and verify

From the repository root:

```sh
python3 -m http.server 8765 --directory docs
```

Open `http://127.0.0.1:8765/` (Korean) and `/en/` (English). Edit `tools/templates/home.ko.html`, `tools/templates/feedback.ko.html` and the feature files under `docs/assets/`. Website text lives in `docs/assets/i18n/source.json` (Korean keys and English reference) and the locale catalogs; regenerate every page after changing text:

```sh
python3 tools/build-locales.py
python3 tools/build-locales.py --check
python3 tools/check-site.py
node tools/check-hero-scroll.cjs
node tools/check-interactions.cjs
node tools/check-phone.cjs
node tools/check-phone-text.cjs
node tools/check-narrative.cjs
node tools/check-native-contours.cjs
node --test tools/check-feedback-client.mjs tools/check-locales.mjs
```

The first three commands require Python 3. Controller checks use Node.js; canvas/native checks additionally need `@napi-rs/canvas` from the bundled Codex Node runtime. On this workstation, Node is `/Users/gpt/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node`. Native export/check setup is documented in [architecture/website.md](architecture/website.md).

## Project boundaries

- `docs/`: all published pages, local fonts/vendors/artwork and page controllers.
- `tools/`: repeatable locale generation, native artwork export and regression checks.
- `architecture/`: ownership/build notes, native source hashes and bounded cleanup evidence.

`docs/index.html`, all localized home/feedback pages and their runtime copy are generated from the Korean templates and `assets/i18n/` catalogs. The 30 locale entries mirror the app registry, including distinct simplified/traditional Chinese and Brazilian/European Portuguese. Do not edit generated HTML. The Korean phone demo is intentional in every site language. Phone previews use canvas artwork with browser-rendered SVG text; the canvas text remains available when graphics enhancement cannot mount. Six modules in `growth-motion/` are unchanged copies of the Dayloom design prototype; change the web adapter instead of those modules.

GitHub Pages serves the checked-in `docs/` directly. Preserve `docs/.nojekyll` and `docs/CNAME`; publishing remains the repository's existing Pages setting. There is no custom deploy workflow in this repository.

## Public suggestions and support

`/feedback/` and `/en/feedback/` provide an anonymous suggestions board: optional nickname, votes and single-level comments. Private support remains `contact@myanimalroom.com`. The board is independent of the app's local records and backup account.

- `docs/assets/feedback/`: accessible page controller, API client, public configuration and copy. All localized HTML/runtime copy is generated by `tools/build-locales.py`; edit `tools/templates/feedback.ko.html` and `assets/i18n/` catalogs.
- `services/feedback/`: Cloudflare Worker, D1 migration, API tests and moderation/backup instructions. This directory is outside the GitHub Pages publishing root. Production uses `feedback-api.myanimalroom.com` and the explicitly selected `wrangler.production.jsonc`; default Wrangler configuration is local development.
- Public site keys and resource IDs are configuration, not credentials. Turnstile secrets stay in the Worker; do not put them in `docs/` or Git.

For a local end-to-end preview, keep the static server on `127.0.0.1:8765`, then follow `services/feedback/README.md` to run the API on `127.0.0.1:8789`. Local data and official Turnstile test keys are separate from production. A failed API connection is shown as an error, never as an empty board or a successful submission.

Before publishing, run the static/locale checks, `node --test tools/check-feedback-client.mjs tools/check-locales.mjs`, and `npm test` in `services/feedback`. Deploy and verify the API before publishing the static pages. Existing posts are public; perform UI testing against local data and keep any production smoke data out of the public list after verification.

## Mobile app privacy

The app policy is authored in `tools/templates/app-privacy.ko.html` and `app-privacy.en.html`, then generated at `/app-privacy/` and `/en/app-privacy/`. It stays separate from the website/board policy. Both have Korean/English navigation and sitemap entries; legal copy is not translated by the marketing catalogs. Update both authored versions together and regenerate with `python3 tools/build-locales.py`.
