앱 개인정보처리방침

My Animal Room 모바일 앱에서 처리하는 정보와 이용자의 선택을 안내합니다.

시행일: 2026년 10월 21일

운영자 강보승은 My Animal Room 모바일 앱에서 처리하는 정보와 이용자의 선택을 아래와 같이 안내합니다. 운영자는 앱과 문의 대응에서 자신이 처리하는 정보에 책임을 집니다. 홈페이지와 기능 제안 게시판에는 별도의 웹사이트 개인정보 안내가 적용됩니다.

1. 기기에 저장하는 정보

별도 앱 회원가입 없이 집중, 할 일, 식물 키우기, 방 꾸미기와 기억 기능을 사용할 수 있습니다. 다음 정보는 기능 제공과 기록 표시를 위해 기본적으로 기기의 앱 전용 저장 공간에 보관합니다.

  • 집중 시각·시간·목표·태그, 할 일·반복·완료 정보, 조각의 획득·사용 내역
  • 방 배치, 동물 애칭과 식물 성장 상태, 작성한 글·날짜, 선택한 사진과 앱에서 만든 방 이미지
  • 언어·알림·소리 등 앱 설정과 백업 관련 기기 설정

사진 선택 화면에서 고른 파일은 앱 안에 복사합니다. 원본 사진을 지우거나 사진 접근 권한을 바꿔도 앱 복사본은 남을 수 있습니다. 사진 파일 자체에 포함된 정보도 함께 저장될 수 있습니다.

일반적인 앱 사용 과정에서 이 기록을 운영자의 서버로 보내지 않습니다. 현재 앱에는 광고나 광고 추적 기능, 운영자를 위한 외부 이용 분석 전송 기능을 사용하지 않습니다.

2. 선택 기능: Dropbox 연결과 백업

Dropbox 연결 없이 기본 기능을 사용할 수 있습니다. 연결하면 Dropbox에서 받은 계정 ID와 이메일을 백업 계정의 구분·표시에 사용하며 기기에서 관리합니다. 이 계정 정보와 인증 토큰을 운영자의 서버로 보내지 않습니다. Dropbox 로그인은 브라우저에서 진행하며 앱이 Dropbox 비밀번호를 받거나 저장하지 않습니다.

앱은 연결 계정의 확인과 백업 목록 조회·다운로드·저장·삭제에 필요한 권한을 요청합니다. 파일 접근 범위는 이 앱의 Dropbox App Folder로 제한됩니다.

백업할 때 기록·설정의 복사본, 사진 등 미디어와 복원을 확인하기 위한 정보를 기기에서 이용자의 Dropbox App Folder로 직접 전송합니다. 메타데이터에는 백업·설치·데이터 묶음의 식별값, 생성 시각·종류, 파일 경로·크기·무결성 확인값 등이 포함됩니다. 운영자의 중계 저장 서버를 거치지 않습니다.

수동 백업은 이용자가 실행합니다. 자동 백업은 기본으로 꺼져 있으며, 켠 경우 앱 사용 중 Wi-Fi에 연결되고 변경된 데이터 등 실행 조건을 충족할 때 진행합니다. 새 자동 백업이 성공한 뒤 오래된 자동 백업을 정리하여 최근 3개를 유지합니다. 정리에 실패하면 3개를 초과할 수 있습니다. 수동 백업은 자동 정리 대상이 아니며 이용자가 별도로 삭제합니다.

복원을 확인하면 현재 사용하는 앱 데이터가 선택한 백업의 데이터로 바뀝니다. 백업과 복원에 받은 정보를 해당 계정의 연결·백업·복원 기능에 사용합니다. Dropbox의 인증·저장 서비스 자체에서 처리하는 계정·접속·파일 정보에는 Dropbox 개인정보처리방침이 적용됩니다.

3. 보관과 삭제

기기의 기록은 앱이 제공하는 열람·수정·삭제 기능으로 관리할 수 있습니다. 기기 기록 삭제, 자동 백업 끄기, Dropbox 연결 해제, 원격 백업 삭제는 서로 다른 작업입니다. 기기 기록을 지워도 이전 백업에 해당 기록이 남을 수 있습니다.

자동 백업을 꺼도 기존 백업은 남습니다. 연결 해제는 추가 백업·복원을 중단하고 기기의 보안 저장소에서 연결 인증 정보를 제거하며, 사용 가능한 토큰이 있으면 Dropbox에 철회를 시도합니다. 연결 해제는 기기의 기록이나 기존 원격 백업을 삭제하지 않습니다. Dropbox에서도 연결 앱의 접근 권한을 관리할 수 있습니다.

앱의 백업 목록에서는 수동 백업을 선택해 삭제할 수 있습니다. 전체 원격 보관본을 제거하려면 자동 백업을 끄고 Dropbox에서 앱 전용 폴더의 파일도 별도로 관리해야 합니다. 앱은 삭제한 백업이 다시 나타나거나 복원되는 것을 막기 위해 식별값·시각·파일 경로·크기·무결성 정보 등 기술 메타데이터를 담은 삭제 표시 파일을 App Folder에 남깁니다. 이 표시 파일에는 기록 본문이나 사진 파일 자체가 들어 있지 않습니다. 삭제 실패로 일부 파일이 남으면 정리가 끝나기 전까지 보관될 수 있습니다.

백업·다운로드·복원 과정에서 기기에 만든 작업 복사본과 계정별 백업 설정은 작업 완료나 연결 해제 뒤에도 남을 수 있습니다. 원격 자동 백업의 최근 3개 정책은 이 로컬 복사본에 적용되지 않습니다. 운영체제의 앱 데이터 보관·백업·기기 이동 기능은 Dropbox 백업과 별개입니다.

Dropbox에서 삭제한 파일에도 계정과 요금제에 따른 Dropbox의 보관·복구 정책이 적용될 수 있습니다. 앱에서 삭제했다고 모든 외부 보관본이 즉시 영구 삭제되는 것은 아닙니다.

4. 문의 메일

문의 기능은 기본 메일 앱에서 초안을 엽니다. 초안에는 앱 버전, 운영체제·버전, Android API 수준(해당하는 경우), 앱 언어가 포함됩니다. 전송 전에 내용을 확인·수정할 수 있으며 자동으로 전송하지 않습니다. 이용자가 전송하면 운영자는 발신 이메일 주소와 이용자가 적거나 첨부한 내용, 포함된 기기 정보를 문의 답변과 오류 확인에 사용합니다. 앱 기록 전체나 사진을 자동으로 첨부하지 않습니다.

문의 이메일은 Cloudflare의 이메일 전달 서비스를 거쳐 Gmail에서 수신·처리합니다. 문의 해결과 동일 문제의 후속 대응을 위해 처리 완료 후 최대 3개월 보관하며, 그 전에 보관 필요가 없어지면 삭제합니다. 보관 기간이 끝나면 메일 서비스의 삭제 기능으로 휴지통에서도 제거합니다. 문의와 관련한 개인정보의 열람·정정·삭제·처리정지 요청은 아래 연락처로 보낼 수 있습니다.

이메일 서비스 제공 과정의 정보 처리는 Cloudflare 개인정보처리방침과 Google 개인정보처리방침에서 확인할 수 있습니다.

5. 선택과 권리 행사

사진·알림 권한은 기기 설정에서 관리할 수 있고, Dropbox 자동 백업과 연결은 앱 설정에서 관리할 수 있습니다. 선택 기능을 사용하지 않아도 해당 기능을 제외한 기본 기능을 사용할 수 있습니다.

운영자가 처리하는 개인정보에 관한 요청은 contact@myanimalroom.com으로 보내 주세요. 필요한 범위에서 본인 또는 요청 권한을 확인하고 적용 법령에 따라 처리합니다. 기기에만 있는 기록은 운영자가 원격으로 열람·삭제할 수 없으므로 기기에서 관리하는 방법을 안내합니다.

6. 보호 조치

기록과 사진은 앱 전용 저장 공간에 보관합니다. Dropbox 통신에는 HTTPS를 사용하고 복원 전 파일 크기와 무결성을 확인합니다. 갱신 토큰은 기기의 보안 저장소에, 접근 토큰은 실행 중 메모리에 보관하며 기록 데이터베이스나 백업에 넣지 않습니다. 앱 자체의 종단간 암호화는 제공하지 않습니다.
