應用程式隱私權政策

說明 My Animal Room 行動應用程式如何處理你的資料，以及你可以作出的選擇。

生效日期：2026 年 10 月 21 日

My Animal Room 行動應用程式由 강보승 營運。營運者對於在應用程式及回覆聯絡訊息時自行處理的資料負責。本政策說明應用程式處理的資料及使用者的選擇。網站與功能建議留言板另適用網站隱私說明（英文）。

1. 儲存在裝置上的資料

不需註冊應用程式帳號，即可使用專注、待辦事項、養成、房間布置與日記功能。為提供這些功能並顯示紀錄，以下資料預設儲存在裝置的應用程式專用儲存空間中：

  • 專注的時間點、時長、目標與標籤，待辦事項、重複設定與完成狀態，以及碎片的獲得與使用紀錄
  • 房間配置、動物暱稱、養成對象的成長與完成狀態、已解鎖的主題與物品，以及已發現的事件紀錄
  • 日記文字與日期、所選照片，以及在應用程式中產生的房間圖片
  • 語言、通知、音效等應用程式設定，以及裝置上的備份相關設定

透過系統照片選擇畫面選取的檔案會複製到應用程式內。即使刪除原始照片或變更照片存取權限，應用程式內的副本仍可能保留。照片檔案本身包含的資訊也可能一併儲存。

一般使用過程中，這些紀錄不會傳送至營運者的伺服器。目前的應用程式不使用廣告、廣告追蹤功能，也不會為營運者向外部傳送使用情況分析資料。

2. 選用功能：連接 Dropbox 與備份

不連接 Dropbox 也能使用基本功能。連接後，應用程式會在裝置上管理從 Dropbox 取得的帳號 ID 與電子郵件地址，用來辨識及顯示備份帳號。這些帳號資料與驗證權杖不會傳送至營運者的伺服器。Dropbox 登入在瀏覽器中進行，應用程式不會接收或儲存你的 Dropbox 密碼。

應用程式會要求辨識已連接帳號，以及查詢備份清單、下載、儲存與刪除備份所需的權限。檔案存取範圍僅限於本應用程式的 Dropbox App Folder（應用程式專用資料夾）。

備份時，紀錄與設定的副本、照片等媒體，以及用來確認還原結果的資料，會直接從裝置傳送至你的 Dropbox App Folder。中繼資料包含備份、安裝與資料集的識別值、建立時間、備份類型、檔案路徑、大小及完整性驗證值等。傳輸不會經過營運者的中繼儲存伺服器。

手動備份由你自行執行。自動備份預設關閉；啟用後，會在使用應用程式、裝置已連接 Wi-Fi，且符合資料有變更等執行條件時進行。新的自動備份成功後，應用程式會清理較舊的自動備份，保留最近 3 份。若清理失敗，可能保留超過 3 份。手動備份不會自動清理，需由你另行刪除。

確認還原後，目前使用中的應用程式資料會被所選備份的資料取代。備份與還原過程取得的資料會用於該帳號的連接、備份及還原功能。Dropbox 本身的驗證與儲存服務所處理的帳號、連線及檔案資料，適用其隱私權政策。

3. 保留與刪除

你可以透過應用程式提供的檢視、編輯與刪除功能管理裝置上的紀錄。刪除裝置上的紀錄、關閉自動備份、中斷 Dropbox 連接，以及刪除遠端備份，是不同的操作。即使刪除了裝置上的紀錄，先前的備份仍可能保留這些紀錄。

關閉自動備份不會移除既有備份。中斷連接會停止後續備份與還原，移除裝置安全儲存空間中的連接憑證，並在有可用權杖時嘗試向 Dropbox 撤銷授權。中斷連接不會刪除裝置上的紀錄或既有遠端備份。你也可以在 Dropbox 中管理已連接應用程式的存取權限。

你可以在應用程式的備份清單中選取個別手動備份並刪除。若要移除所有遠端副本，需先關閉自動備份，並另外在 Dropbox 中管理應用程式專用資料夾內的檔案。為防止已刪除的備份再次出現或被還原，應用程式會在 App Folder 中保留刪除標記檔案，內含識別值、時間、檔案路徑、大小及完整性資訊等技術中繼資料。標記檔案不包含紀錄本文或照片檔案本身。若刪除失敗而留下部分檔案，這些檔案可能保留至清理完成。

備份、下載及還原過程中在裝置上建立的工作副本，以及各帳號的備份設定，可能在作業完成或中斷連接後仍然保留。遠端自動備份保留最近 3 份的規則不適用於這些本機副本。作業系統的應用程式資料保留、備份與裝置移轉功能，與 Dropbox 備份各自獨立。

在 Dropbox 中刪除的檔案，仍可能適用依帳號與方案而定的 Dropbox 保留與復原規則。在應用程式中刪除備份，並不代表所有外部副本都會立即永久刪除。

4. 聯絡郵件

聯絡功能會在預設電子郵件應用程式中開啟草稿。草稿包含應用程式版本、作業系統及版本、Android API 等級（如適用），以及應用程式語言。你可以在傳送前檢查及修改內容，郵件不會自動傳送。若你選擇傳送，營運者會使用寄件者電子郵件地址、你填寫或附加的內容，以及包含的裝置資訊，回覆問題及檢查錯誤。應用程式不會自動附加全部應用程式紀錄或照片。

聯絡郵件會經由 Cloudflare 的電子郵件轉寄服務，於 Gmail 中接收及處理。為解決聯絡事項並跟進相同問題，郵件會在處理完成後保留最多 3 個月；若在此之前已無保留必要，則會提前刪除。保留期間屆滿後，會使用郵件服務的刪除功能，連同垃圾桶中的郵件一併移除。若要請求查閱、更正、刪除或停止處理聯絡郵件中的個人資料，可透過下方聯絡方式提出。

有關電子郵件服務供應商如何處理資料，請參閱 Cloudflare 隱私權政策與 Google 隱私權政策。

5. 你的選擇與權利行使

你可以在裝置設定中管理照片與通知權限，並在應用程式設定中管理 Dropbox 自動備份與連接。不使用選用功能時，仍可使用該功能以外的基本功能。

如需就營運者處理的個人資料提出請求，請寄信至 contact@myanimalroom.com。營運者會在必要範圍內確認本人身分或提出請求的權限，並依適用法令處理。僅儲存在裝置上的紀錄，營運者無法遠端查閱或刪除，但會說明如何在裝置上管理。

6. 保護措施

紀錄與照片儲存在應用程式專用儲存空間中。與 Dropbox 的通訊使用 HTTPS，並在還原前檢查檔案大小與完整性。更新權杖儲存在裝置的安全儲存空間，存取權杖則保留在執行中的記憶體內，不會放入紀錄資料庫或備份。應用程式本身不提供端對端加密。

7. 聯絡人與政策變更

營運者及個人資料聯絡人：강보승
電子郵件：contact@myanimalroom.com

若資料的處理目的、項目或保留方式有變更，會更新本政策與生效日期，並在應用程式或網站上公告。適用法令如要求另行辦理程序，將依規定辦理。
