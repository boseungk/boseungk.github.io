# Website asset sources

Artwork is copied or rendered from the Dayloom app repository without redrawing or editing it. The tables between the
`generated:` markers below are written by `tools/assets/` (`node tools/assets/build-art.mjs --sources-md`,
`build-fonts.mjs`, `tools/rooms/build-room-assets.mjs`); do not edit them by hand. The sections here are the parts
the generators do not own.

## Fonts

`OFL-LINESeedKR.txt` is the licence of LINE Seed KR, which the Korean font subsets under `fonts/` are cut from. The master
file `tools/assets/src/fonts/LINESeedKR-Regular.otf` is a byte-identical copy of Dayloom's
`assets/fonts/LINESeedKR-Regular.otf` and is not published. No LINE Seed bold font file was found in the app
assets/source tree. The other languages use the fonts the app embeds for them (Dayloom `assets/fonts/README.md`), subset
from the Dayloom checkout without copying the masters; each family's OFL 1.1 licence ships beside its subsets as
`fonts/OFL-<family>.txt`. Noto Sans SC and TC reserve the name "Source", which their names do not use. LINE Seed TW reserves
its own name, so the site does not publish a subset of it and uses the app's Noto Sans TC for Traditional Chinese. The
subsets are listed in the generated font table.

## Website chrome

Website chrome follows current app tokens: white paper, ink `#473E3B`, muted `#776B66`, neutral soft `#F5F5F5`, Oat button `#E1CABF`, Oat selection `#EFE3DD`, and 8px controls. Theme artwork has its own palette.

## App icon and selection wash

The browser icons are size exports of the icon configured by Dayloom's `app.json` (`assets/images/app-icon/icon.png`), listed in the generated site-icon table. `app-icon-source.json` records the source hash and output sizes; regenerate with `node tools/build-site-icons.cjs`. No artwork is redrawn and no app source is modified.

`ui/selection-spec.js` is generated by `tools/export-selection-spec.cjs` directly from Dayloom's `LiquidChoiceBackdrop`, `ActionChoiceLabel`, default Oat theme and Reanimated timing contract. Source hashes are in `architecture/native-selection-sources.json`. The web adapter measures the padded inner labels; `selection-motion.js` follows the native analytic spring and 110ms in-out-quadratic opacity.

## Room renders and growth artwork

The room images under `art/` are rendered from the native room compositor by `tools/render-customize.cjs` (masters in `tools/assets/src/customize/`, per-slot crop evidence in the `*render-evidence.json` files beside them), reading Dayloom without modifying it, and encoded by `tools/assets/build-art.mjs`.

`tools/export-growth.cjs` reads production Dayloom `src/world/drawn/growth/art-flower.ts` and its shape helpers and writes the growth stage SVGs `tools/assets/src/growth/flower-0..4.svg`, which `build-art.mjs` encodes. The source hashes are recorded in `architecture/native-growth-sources.json` and checked by `tools/check-growth.mjs`.

Both native export commands share `tools/native-renderer.cjs`. Its napi-rs contour correction preserves independent SVG subpaths and is covered by `tools/check-native-contours.cjs`; this prevents diagonal triangles in cloud/mineral room art without changing the app source.
