私たちについて。

アプリはもう使えますか？

MyAnimalRoomは、iOS・Android向けに開発中のアプリです。まだ公開されていません。リリース情報は、このサイトと公式チャンネルでお知らせします。

この画面は実際のアプリですか？

アプリのイラストや開発中の画面を使ったデモです。集中・完了・思い出の流れを紹介しており、このサイトでは記録は保存されません。公開時の画面や機能は変更になる場合があります。

動物の仲間はいつ来ますか？

集中を始めると、選んだ仲間がやってきてそばにいてくれます。集中を終えて確認すると、時間帯のしるしが思い出に加わり、自分の空間に戻ります。
